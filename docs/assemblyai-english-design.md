# English DBS integration

An isolated follow-on branch reuses the existing provider-neutral conversation controller and navigation tools, with one AssemblyAI Universal-3.6 Pro stream and ElevenLabs playback. English contributions are never translated. The opening uses Josh’s latest exact wording with user-authored provenance; the remaining questions retain full canonical Waha wording; Scripture is server-retrieved NIV version 111 with exact attribution and individually validated Genesis 1:1–25 verses. Missing source text fails closed before a study starts.

Josh’s exact expanded opening replaces f.001 for this English test and plays once automatically, without a queue wait. Repeat and Previous use the same selected opening; later navigation preserves the remaining Waha questions. The isolated server prepares official NIV text in memory before listening; Start reuses that validated source for up to five minutes and opens ASR before inviting speech. Older preparation is reverified. No Bible text is saved to disk. Later conversational decisions come directly from the active Codex harness session through an owner-token-protected, loopback-only in-memory request queue. No external LLM API/key/model script is used. The loopback decision interface rejects browser requests; tokens never reach JavaScript. Pending decisions time out without changing the lesson. This test requires the active Codex session; it is not a standalone unattended service.

Speaker names remain separate from vendor labels. Introductions can be recorded as unverified session-only self-reports; cautious same-voice confirmation uses the existing ledger. Revision revokes confirmed bindings and the roster. Participants can continue the study without waiting for biometric-style enrollment. No voice profiles are generated. The human organizer obtains consent before startup, outside William’s UX.

Stop terminates the billed stream and clears session state. Pause interrupts playback while preserving remaining prompts; Resume replays those prompts. Actual playback is gated from ASR and cannot be treated as participant speech. Voice wake interruption is not enabled in this slice; the Pause control interrupts reading and Resume preserves the destination. Offline checks cover source validation, harness authentication/timeout, final dedup/revisions, original question/navigation, playback gating and cleanup; real English testing follows on loopback port 8095, with the live service and Tailscale unchanged.
